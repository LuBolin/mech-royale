What the four stages are

Training runs four evolution runs back to back. One generation = 16 candidate bots, each scored in about 10 simulated matches; the best ones steer the next generation.

Stages 1–3, step-size tests A/B/C (40 generations each). σ ("sigma") is how far new candidates stray from the current best guess: A = 0.1 (small, careful steps), B = 0.2 (medium), C = 0.35 (large, bold steps). Each test is short; we keep the σ whose final benchmark is highest.

Stage 4, main run (2000 generations) uses that winning σ. It saves its best bot every 25 generations, so a usable bot exists long before it finishes.

Fitness = 0.5 × FFA points + 0.5 × practice points (0–15) for each generation's 16 candidates. The benchmark plays the distribution mean on fixed seeds: 32 practice matches vs house bots, and 16 FFA matches vs 15 default bots. It's the number to compare across runs.
